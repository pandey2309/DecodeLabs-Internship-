# AI Text Sentiment Analyzer

## Project Overview

AI Text Sentiment Analyzer is a Natural Language Processing (NLP) project developed using Python and the VADER Sentiment Analysis library.

The system analyzes user-entered text and classifies it as Positive, Negative, or Neutral.

This project demonstrates the use of a pre-trained AI model for text recognition and sentiment analysis.

---

## Features

- Text Sentiment Analysis
- Positive Sentiment Detection
- Negative Sentiment Detection
- Neutral Sentiment Detection
- Uses Pre-trained AI Library
- Displays Sentiment Scores
- Continuous User Interaction

---

## Technologies Used

- Python
- VADER Sentiment Analyzer
- NLP (Natural Language Processing)

---

## Installation

Install the required package:

```bash
pip install vaderSentiment
```

---

## How to Run

Run the program:

```bash
python sentiment_analysis.py
```
