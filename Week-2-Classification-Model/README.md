# Iris Classification Model

## Overview

This project is a basic machine learning classification model built using Python and Scikit-Learn.

The model uses the Iris Dataset to classify flowers into three species:
- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- Scikit-Learn

## Algorithm Used

Decision Tree Classifier

## Steps Performed

1. Loaded Iris Dataset
2. Explored Dataset Features
3. Split Data into Training and Testing Sets
4. Trained Decision Tree Model
5. Evaluated Model Accuracy

## How to Run

```bash
python classification_model.py
```
