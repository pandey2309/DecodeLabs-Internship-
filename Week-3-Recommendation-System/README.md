# Smart Learning Recommendation System

## Overview

This project is a simple recommendation system developed using Python.

The system takes user interests as input and recommends relevant skills, projects, and books based on predefined preferences.

## Features

* Interest-Based Recommendations
* Skills Suggestions
* Project Recommendations
* Book Recommendations
* Pattern Matching Logic
* User-Friendly Interface

## Technologies Used

* Python
* Dictionaries
* Conditional Statements
* Loops

## How It Works

1. User selects an interest.
2. System matches the interest with stored recommendations.
3. Relevant skills, projects, and books are displayed.
