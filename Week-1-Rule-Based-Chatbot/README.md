# DecodeBot - Rule Based AI Chatbot

## Overview 

DecodeBot is a simple rule-based AI chatbot developed in Python.

It responds to predefined user commands using conditional statements and looping concepts.

## Features

- Greetings Handling
- Date and Time Information
- Help Menu 
- Joke Generator 
- Exit Commands
- Unknown Input Handling

## Technologies Used 

- Pyhton 
- If-Else Statements 
- Loops 
- Datetime Module 

## How to Run 

python chatbot.py
